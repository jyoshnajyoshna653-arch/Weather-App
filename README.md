# 🌤️ Python Weather App

A simple and efficient **Python Weather App** that provides real-time weather information for any city using the OpenWeather API.

The application fetches live weather data and displays important details such as temperature, humidity, wind speed, and current weather conditions.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature information
- 💧 Humidity percentage display
- 🌬️ Wind speed details
- ☁️ Current weather condition
- ❌ Error handling for invalid city names
- ⚡ Fast API-based weather updates

## 🛠️ Technologies Used

- **Python**
- **Requests Library**
- **OpenWeather API**
- **JSON**

## 🔑 API Key Setup

This project requires an OpenWeather API key.

1. Visit OpenWeather and create an account.
2. Generate your API key.
3. Open `app.py`.
4. Add your API key:

```python
API_KEY = "your_api_key_here"
```

## ▶️ Run the Application

```bash
python app.py
```
